# 我的ライブカメラ

只顯示自己想看的公開即時影像（ライブカメラ）的單檔網頁 app。

- 打開 `index.html` 即可使用（建議用 GitHub Pages 發布，YouTube 嵌入在本機檔案模式下有時會被拒絕）。
- 按「＋ 新增鏡頭」可加入：YouTube 直播網址、靜態圖片網址（每 5 分鐘自動更新）、或只放連結。
- 清單存在瀏覽器的 localStorage；預設清單在 `index.html` 的 `DEFAULTS`。
